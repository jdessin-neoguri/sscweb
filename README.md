## 사람 탭 (artists.json)

"사람" 탭에는 `artists.json`에 등록한 사람만 나타납니다. 카드를 열면 그 사람이 **아티스트로 참여한 곡과 작곡·작사가로 참여한 곡**이 함께 나오고, 적어 둔 설명이 목록 위에 표시됩니다.
파일이 없거나 비어 있어도 사이트는 정상 동작합니다(탭에 "아직 등록된 사람이 없습니다"가 표시됨).

```json
{
  "Ralph Siegel": {
    "names": ["Ralph Siegel & Bernd Meinunger", "랄프 지겔"],
    "description": "설명 문장. 여러 줄도 가능합니다."
  }
}
```

- 맨 앞 키가 카드에 표시되는 대표 이름이고, `names`에는 같은 사람의 다른 이름(활동명·그룹명·작곡가 표기·원어 표기 등)을 모두 적습니다.
- 이 이름들이 `sscdbg.json`의 `artist`나 `songwriters`에 나오면 모두 한 카드로 묶입니다. 대소문자·악센트 차이는 무시됩니다.
- `names`와 `description`은 생략할 수 있습니다. 대표 이름과 같은 이름으로 곡이 연결됩니다.
- 곡이 하나도 연결되지 않는 항목은 카드가 만들어지지 않습니다.
- 곡 카드에서 등록된 사람의 이름(아티스트·작곡가)을 누르면 해당 카드로 이동합니다.
- Traditional, Anonymous, 작자미상은 묶이지 않습니다.
